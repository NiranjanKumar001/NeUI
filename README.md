# ScrollCraft 🎨  
A sleek and creative scrolling experience that transforms navigation into an interactive story.  
Built with smooth animations, parallax effects, and seamless transitions — making every scroll feel alive.  

## ✨ Features  
- Smooth, performance-optimized scrolling  
- Creative reveal animations  
- Parallax and depth effects  
- Fully responsive design  

## 🚀 Usage  
Clone the repo and start scrolling:  
```bash
git clone https://github.com/username/scrollcraft.git
cd scrollcraft
npm install
npm run dev
